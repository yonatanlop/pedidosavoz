# PedidosVoz - Android

App Kotlin para meseras/meseros. Pendiente de implementar (fase 3 del proyecto).

Funcionalidad prevista:
- Login contra `POST /api/auth/login`.
- Captura de pedido por voz con `SpeechRecognizer`.
- Confirmación/edición del texto antes de enviar.
- Envío a `POST /api/pedidos` con el token JWT de la mesera.
